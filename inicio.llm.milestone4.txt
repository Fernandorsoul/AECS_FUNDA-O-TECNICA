## 2. O QUE IMPLEMENTAR AGORA (MILESTONE 4)

### 4.1 Verification DAG

Implemente 4 verificadores em `AECS.Application` ou `AECS.Verification`:

**BuildVerifier:**
- Executa `dotnet build` no workspace
- Retorna PASS/FAIL baseado no exit code
- Tipo: Deterministic

**TestVerifier:**
- Executa `dotnet test` no workspace
- Retorna PASS/FAIL baseado no exit code
- Tipo: HighConfidence

**ScopeVerifier:**
- Compara `git diff --name-only` com ScopeDefinition do TaskContract
- Usa ScopeEnforcer existente
- Tipo: Deterministic

**BudgetVerifier:**
- Compara métricas do AgentRunResult com ExecutionBudget
- Usa BudgetEnforcer existente
- Tipo: Deterministic

Cada verificador implementa `IVerifier`:
```csharp
public interface IVerifier
{
    string Name { get; }
    VerificationCategory Category { get; }
    Task<VerificationResult> VerifyAsync(VerificationContext context, CancellationToken ct);
}
```

### 4.2 Decision Engine

Implemente regra de decisão final:

```csharp
public class DecisionEngine
{
    // Regra 1: qualquer verificador obrigatório com Fail → REJECTED
    // Regra 2: todos passam + approval=human → HUMAN_REVIEW_REQUIRED
    // Regra 3: todos passam + approval=none → VERIFIED
}
```

### 4.3 Testes obrigatórios

- BuildVerifier: mock processo, testa PASS/FAIL
- TestVerifier: mock processo, testa PASS/FAIL
- ScopeVerifier: testa com arquivos allowed/forbidden
- BudgetVerifier: testa com budget ok/excedido
- DecisionEngine: testa as 3 regras de decisão
