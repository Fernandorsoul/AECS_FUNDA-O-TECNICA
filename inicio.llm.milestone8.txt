### 2.2 Heuristic Model Selector

```csharp
public class HeuristicModelSelector
{
    // Dado histórico de execuções, seleciona melhor modelo:
    // - Qual modelo tem maior taxa de sucesso para este tipo de task?
    // - Qual modelo tem menor custo para este risk level?
    // - Fallback: modelo padrão por risk level
}
```

### 2.3 Heuristic Budget Optimizer

```csharp
public class HeuristicBudgetOptimizer
{
    // Dado histórico, sugere budget otimizado:
    // - Quantos tokens esta classe de task normalmente usa?
    // - Qual o custo médio por risk level?
    // - Ajusta budget para evitar waste sem comprometer sucesso
}
```

### 2.4 Adaptive Controller (orquestrador)

```csharp
public class AdaptiveController
{
    // Combina heurísticas para tomar decisão adaptativa:
    // 1. Consulta histórico
    // 2. Seleciona modelo
    // 3. Otimiza budget
    // 4. Retorna ExecutionPlan adaptativo
}
```
