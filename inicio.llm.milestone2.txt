## 3. O QUE IMPLEMENTAR AGORA (MILESTONE 2)

Seu objetivo é implementar o **Agent Runtime**, que permite executar um coding agent de forma controlada.

### 3.1 OllamaAdapter

Implemente `IAgentAdapter` em `AECS.Infrastructure`:

```csharp
public class OllamaAdapter : IAgentAdapter
{
    // POST http://localhost:11434/api/chat
    // Envia: task objective + acceptance criteria + codebase context
    // Recebe: código modificado
    // Retorna: AgentRunResult com stdout, stderr, tokens, duração, arquivos modificados
}
```

Requisitos:
- Use `HttpClient` (sem SDK de fornecedor)
- O prompt deve instruir o modelo a modificar apenas os arquivos necessários
- Capture: response text, token counts (prompt_tokens, completion_tokens), duration
- Parseie a resposta para extrair arquivos modificados
- Trate erros de conexão (Ollama não rodando)
- O domínio NÃO pode depender de detalhes do Ollama

### 3.2 Docker Sandbox

Implemente isolamento de execução em `AECS.Infrastructure`:

```csharp
public class DockerSandbox
{
    // Cria container com .NET SDK
    // Monta workspace como volume
    // Executa com timeout
    // Captura stdout/stderr
    // Descarta container após execução
}
```

Requisitos:
- Copie o repo para diretório temporário antes de montar no container
- Use `mcr.microsoft.com/dotnet/sdk:10.0` como imagem base
- Timeout configurável via `CancellationToken`
- Sem acesso à rede (exceto Ollama se necessário)
- Resource limits básicos (memória, CPU)
- Container descartável (criado por execução, destruído após)

### 3.3 ExecutionController

Implemente `IExecutionController` em `AECS.Application`:

```csharp
public class ExecutionController : IExecutionController
{
    // Dado um TaskContract, produz um ExecutionPlan
    // Seleciona modelo baseado no RiskLevel
    // Define budget baseado no contrato
    // Retorna ExecutionPlan
}
```

Mapeamento de modelo por risco:
- R0/R1 → `deepseek-coder:1.3b` ou `codellama:3b`
- R2/R3 → `codellama:7b` (mais lento, melhor qualidade)

### 3.4 Testes obrigatórios

Crie testes para:
- `OllamaAdapter` — mock do HttpClient, testa parsing de resposta
- `DockerSandbox` — testa criação/destruição de container (integration test)
- `ExecutionController` — testa seleção de modelo por risco
