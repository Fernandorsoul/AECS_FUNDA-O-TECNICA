# AECS_FUNDA-O-TECNICA
O AECS é um **sistema de controle adaptativo para engenharia de software agêntica**.  A proposta não é criar “mais um Copilot”, “mais um agente que escreve código” ou “mais um linter com IA”.  O objetivo é construir uma camada independente entre:  - o desenvolvedor; - os agentes de programação; - os modelos de IA; - o repositório;
